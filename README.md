# Pixel Vault - S4 Layouts

Site fictif de reviews et actualités Jeux Vidéo, conçu dans le cadre de la **Semaine 4** de la formation Développeur web Fullstack à [Akieni Academy] - Cohorte 2.

## Objectif

Maitriser CSS Flexbox et Grid pour construire des interfaces modernes et responsives, sans aucune Media Query.

## Livrables

| #   | Livrable                       | Technique     | Fichier                 |
| --- | ------------------------------ | ------------- | ----------------------- |
| 01  | Barre Nav sticky et responsive | Flexbox       | index.html + about.html |
| 02  | Holy Grail Layout              | Grid          | about.html              |
| 03  | Bento Gallery                  | Grid          | index.html              |
| 04  | Card Deck adaptatif            | Grid auto-fit | index.html              |
| 05  | SaaS Hero avec superposition   | Flexbox       | index.html              |

## Technologies

- HTML5 sémantique
- CSS3 (Flexbox, Grid, `auto-fit`, `minmax`)

## Contraintes respectées

- Zéro Media Query
- Projets 100% originaux
- Aucune erreur sémantique HTML
